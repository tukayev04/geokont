# Интерактивная веб-игра «Геоконт» (Геоборд) 🇰🇿
**Республиканский конкурс детских цифровых проектов (РК)**

Интерактивная образовательная веб-игра «Геоконт» разработана для детей дошкольного (4–6 лет) и младшего школьного возраста (7–10 лет) на основе методики развивающих игр В.В. Воскобовича с глубокой интеграцией этнопедагогики Казахстана.

---

## 🌟 Ключевые особенности проекта

### 1. Архитектура и технологии
- **Чистый стек**: HTML5, Vanilla CSS3, JavaScript (ES6+ Canvas 2D API).
- **100% автономность**: без внешних библиотек, работает локально без интернета на любых интерактивных панелях, планшетах и компьютерах.
- **Встроенный аудио-синтезатор (Web Audio API)**: генерация звуков натяжения резинки (пружинный твинг), щелчка штырьков, победного фанфара и мягкой релаксационной музыки.
- **Речевой синтез (Web Speech API)**: голосовое озвучивание подсказок маскота на казахском (`kk-KZ`) и русском (`ru-RU`) языках для не умеющих читать малышей.

### 2. Игровое поле и координатная сетка
- **8-лучевая роза ветров Воскобовича**:
  - Центральный штырек **«О»** (Орталық / Центр).
  - 8 лучей: **К** (Қызыл/Красный), **О** (Қызғылт сары/Оранжевый), **Ж** (Сары/Желтый), **З** (Жасыл/Зеленый), **Г** (Көгілдір/Голубой), **С** (Көк/Синий), **Ф** (Күлгін/Фиолетовый), **Б** (Ақ/Белый).
  - На каждом луче по 4 крупных штырька с четкими координатами (К1, К2, К3, К4 и т.д.). Всего **33 штырька**.
  - Увеличенная сенсорная зона (Hit-Area) для комфортного управления пальцами на сенсорных досках.

### 3. Режимы игры
1. **«Режим Обучения и Сказки» (Оқыту мен ертек)**:
   - Интерактивный проводник — **Барсенок Алан** (символ Казахстана в национальной тюбетейке-тақия).
   - Пошаговое интерактивное знакомство с полем, центром, цветами лучей и координатами.
2. **«Сборка по координатам / Шифру» (Шифр тапсырмалары)**:
   - 3 категории сложности:
     - 🟢 **Жеңіл (Простой)**: Геометрические фигуры (Үшбұрыш, Шаршы, Ромб, Жұлдыз).
     - 🟡 **Орташа (Средний)**: Буквы и цифры («А» әрпі, цифры «1», «4», Күн сағаты).
     - 🦅 **Ұлттық (Национальный / Конкурсный)**: Казахские национальные орнаменты и символы:
       - *«Қошқар мүйіз»* (Бараний рог — символ изобилия и достатка)
       - *«Түйе табан»* (След верблюда — знак верности и стойкости)
       - *«Бәйтерек»* (Символ столицы Казахстана и древо жизни)
       - *«Киіз үй» (Шаңырақ)* (Традиционная юрта и очаг)
   - Динамический предпросмотр (Mini-Canvas), подсказка следующей точки (💡 Көмек) и праздничная анимация конфетти при победе.
3. **«Свободное творчество» (Еркін шығармашылық)**:
   - Палитра из 7 цветов резинок, включая фирменный лазурно-золотой казахский градиент.
   - Готовые шаблоны (Кораблик, Домик, Бабочка, Ракета).
   - Экспорт готового шедевра в **PNG-картинку высокого разрешения** с национальным орнаментальным обрамлением, именем автора и печатью конкурса.

### 4. Критерии доступности и инклюзивности (Inclusivity)
- **Двуязычие**: переключатель KAZ / RUS в один клик.
- **Высококонтрастный режим (👁️ Контраст)**: специальная темная тема с неоновой подсветкой штырьков для слабовидящих детей и ярких проекционных досок.
- **Поддержка сенсорных жестов**: одновременная поддержка одиночных кликов (Tap-Tap) и плавного перетягивания (Drag-and-Snap) с отключением случайной прокрутки страницы на мобильных устройствах.

## 🚀 Как запустить игру

1. Откройте файл `index.html` в любом современном браузере (Google Chrome, Microsoft Edge, Safari, Firefox).
2. Или запустите локальный сервер:
   ```bash
   node -e "const http=require('http'),fs=require('fs'),path=require('path');http.createServer((q,s)=>{let f=path.join(__dirname,q.url==='/'?'index.html':q.url);fs.readFile(f,(e,d)=>{s.end(e?'404':d);});}).listen(3000,()=>console.log('http://localhost:3000'));"
   ```
3. Откройте в браузере: `http://localhost:3000`.
